What it does

One accelerator, seven jobs

Classify
Priority, sentiment, request type and product are filled in as the record arrives, along with any question you add later.
Translate
Messages in other languages are translated into English beside the original, which is never overwritten.
Filter spam
Junk is spotted first and moved to its own queue before anyone spends time on it.
Summarise
One button turns a long record, with its emails and tasks, into a few sentences.
Draft and send replies
New leads get a first reply written for their enquiry. Their answers are tracked on the lead.
Roll out by team
Switch it on for chosen queues only, so teams can adopt it one at a time.
Track usage and cost
A dashboard shows how often the AI ran, how well it did and what it cost.
Install

Built to install like an app

Zeus is designed to ship as a Salesforce managed package. A business installs it, finishes three short setup steps, and the first record that arrives is answered. Nothing is rewritten for the new org.

  1. 1

    Install the package

    One install adds the app, its screens and its settings to the org.

  2. 2

    Connect an AI provider

    Use the AI account the business already has, or Salesforce Einstein.

  3. 3

    Write the first question

    Pick the field for the answer. The next record that arrives gets one.

working on day one

Setup is configuration, with no code to change. Improvements would reach every org as a package upgrade. Packaging is the next step: today Zeus is deployed straight into each org.

Why teams want it

What it changes for a Salesforce business

  • Service teams

    A queue that arrives sorted

    Urgent cases are flagged, foreign-language cases are readable and spam is gone before an agent opens the list.

  • Sales and marketing

    Leads answered in moments

    Each new lead is tagged with what it is asking for and receives a relevant first reply. Responses are tracked, so nobody chases a lead that already answered.

  • Admins and business owners

    Change it the day you ask

    A new question or a reworded one is a form, with no development ticket and no release to wait for.

  • Finance and IT

    No lock-in, no surprise bills

    The cost of every AI call is visible, and the provider can be swapped when pricing or policy changes.

  • Consulting partners

    Configure it, don't rebuild it

    The same package is installed for each client and set up by configuration, so the second rollout is far quicker than the first.

  • Any department

    Built for any object

    It is designed to work on any Salesforce object. So far it has run on Cases and Leads.

Status

Where it stands

Working today

  • Runs end to end on AWS Bedrock and on Salesforce Einstein.
  • Cases and Leads: classification, translation from Spanish, French, German and Italian, spam filtering, summaries, and drafted replies with reply tracking.
  • An admin app for setting it up, with a usage and cost dashboard.

Not done yet

  • Azure AI Foundry and Google Vertex AI are supported by the design but have not been run.
  • Not yet published as a managed package. Today it is deployed straight into each org.
  • Built and demonstrated in sandboxes. It has not been deployed to production.
  • The figures on this page come from a small demo data set.
